# datos/horario/

`bizkaibus.sqlite.xz`: the timetable database used by the paired comparison of paper 2 (`articulo-comparacion/`), built
by the Bide+ app from the Bizkaibus GTFS published on 25 September 2026 (valid from 24 September to 24 November 2026, so
it covers the whole capture week). Decompress with `xz -dk bizkaibus.sqlite.xz`. Its schema is described in the technical
report. Derived from open data of the Diputación Foral de Bizkaia; CC BY 4.0 with attribution.
